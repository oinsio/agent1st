# Изменения версии 2.1 относительно 2.0 и их происхождение

**Назначение:** `definition.md` версии 2.0 записан без отсылок к проектам, происхождение его правил лежит в `definition-evidence.md`. Этот файл делает то же для правок версии 2.1: каждая правка, разбор, из которого она пришла, и калибровки, на которых она подтверждена или опровергнута. Полные факты в `rerun-candidates.md`, вердикты по версии 2.1 в `rerun-v2.1.md`.

Обозначения калибровок: curl, SQLite, Инц (отрицательный контроль инцидентов), CP (Clear Progress), GF (Gnomish Factory), herdr, fah (flutter_agent_harness), Doc (Documenso), GL (GitLab.com).

## 4) Что отвергнуто или отложено

| Предложение | Решение | Причина |
|---|---|---|
| Н-Польз как отдельный критерий для CLI и API | отвергнуто | единственное ДА у curl получено артефактами Я10; это уточнение, не критерий |
| Н-Угрозы отдельно от Н-Трасс | отвергнуто | ни одного ДА; неотличим от трассировки на всех проектах |
| Линтер слабых примитивов как артефакт по умолчанию Н24 | переведён в замены | не найден ни в одном проекте |
| «Деградация абсорбируется масштабированием» как замена Н20 | отвергнуто | масштабирование переводит регрессию в счёт за хостинг, не делает её видимой |
| Нагрузочный стенд в ядре | отвергнуто | правило 6 §3: для библиотеки и внутреннего инструмента дороже дефекта; для типа «под нагрузкой» артефакт по умолчанию |
| Н-ПДн в ядро для компонентов с данными | отложено | условие включения «данные другого субъекта» само есть ось §6 |
| Градация приватного в §8 | отложено в §10 | один проект, SQLite; правило нужно проверить на втором |
| Защищённая связь сервис к сервису отдельным критерием | вошло в Н24 | «транспорт шифрован и проверяет контрагента» покрывает и клиентов без веб-интерфейса |
