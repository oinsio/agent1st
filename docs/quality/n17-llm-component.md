# Н17 «компонент вызывает LLM»: критерий по типу компонента вместо критерия по эффекту

**Задача:** критически разобрать Н17 из `definition.md` версии 2.1: эффект «если компонент вызывает LLM: вывод недоверен, агентность ограничена, потребление ограничено; недоверенный контент в контексте модели не является инструкцией», условие «компонент с LLM», девять артефактов. `definition.md` не меняется: выводы записаны кандидатами в правку следующей версии.

**Метод.** Эффекты и артефакты разложены по свойствам и существующим критериям; каждый артефакт проверен на наблюдённость в четырёх калибровках, где Н17 применим: Gnomish Factory ДА, flutter_agent_harness ДА, GitLab.com ДА (incident-automation), Documenso ЧАСТИЧНО. Продолжает `owasp-crosscheck.md` §3–§4.

---

## 1) Итог

Н17 единственный критерий определения, собранный по типу компонента, а не по эффекту. Поэтому под одним кодом лежат шесть эффектов из четырёх свойств, вердикт один, и по нему не видно, что именно выполнено. Для типа «хранит данные» определение так не поступает: Н6, Н14, Н22 стоят в разных свойствах с одним условием. LLM должен устроиться так же. Собственный эффект у Н17 один, и он нигде больше не записан: действие, вызванное недоверенным контентом, не превышает яруса, доступного пользователю.

---

## 2) Десять замечаний

### 2.1 Шесть эффектов, один вердикт

Вывод недоверен; агентность ограничена; потребление ограничено; контент не инструкция; из артефактов ещё модель прибита по версии и Я21 к извлечённым документам. Documenso получил ЧАСТИЧНО за два из шести, по вердикту не видно, какие. Н25 разделён на подпункты ровно по этой причине.

### 2.2 Свойство Д верно для меньшей части

«Вывод недоверен» это Н3, модель как внешний источник. «Агентность ограничена» это Я6, разрушительное подтверждается. «Потребление ограничено» это Н4 и Г. К Д относятся секреты, инъекция, доступ к извлечённым документам.

### 2.3 У «вывод недоверен» нет артефакта

Ни один из девяти артефактов не доказывает недоверие к выводу. Доказывают: проверка схемы ответа; разбор ответа как данных, не как кода; подтверждение человеком до эффекта, как у Documenso с черновиком полей; двойник модели в обвязке, возвращающий враждебный и повреждённый вывод, с негативными тестами по Я3. Ни одна калибровка такого двойника не записала, хотя у Gnomish Factory есть WireMock для зависимостей, а у flutter_agent_harness задача с моками. Нужен факт.

### 2.4 «Не является инструкцией» нефальсифицируемо как абсолют

Полной защиты от инъекции нет. Карантин и типизированный недоверенный текст это механизмы, а §3 засчитывает эффект. Проверяемая форма: действие, вызванное контентом, не превышает яруса, доступного пользователю, и это проверено корпусом инъекций в обвязке. У flutter_agent_harness корпус есть, сорок файлов тестов инъекций и эксфильтрации, но артефактом записан карантин, а не тест.

### 2.5 Три дубля после v2.1

«Секреты никогда в тексте чата» это Н23, где транскрипты названы прямо. «Я21 применяется к извлечённым документам» уже записано в Я21. «Если компонент вызывает LLM» в эффекте повторяет условие.

### 2.6 «Модель прибита по версии, см. С6» путает продукт и среду

С6 про инструменты агента, пишущего код; §7 говорит «это не критерии ПО». Модель внутри продукта это зависимость продукта, Я15. «Прибита» часто невозможно: провайдеры снимают версии. Проверяемый эффект: версия модели в конфигурации, смена модели это изменение с прогоном. Ни одна калибровка пиннинг не проверила; `rerun-v2.1.md` записал «нужен факт» у обоих агентных проектов. Артефакт по умолчанию, не наблюдённый ни разу, по методу определения гипотеза.

### 2.7 «Идемпотентные правки с сохранением правок человека» след одного проекта

Это бот GitLab, правящий issue между маркерами. Версия 2.0 вычищала отсылки к проектам; этот артефакт остался в форме, узнаваемой только по той калибровке. Общая форма есть, Я6: правка автомата не уничтожает работу человека.

### 2.8 Условие слишком грубое

«Компонент с LLM» объединяет распознавание полей с подтверждением человеком, агента с инструментами и систему, читающую чужие тикеты. Documenso получил полный список, из которого ярусы, перехватчик и выключатель к нему не относятся, и ЧАСТИЧНО за недостающее. Условие должно ветвиться, как в Н25: есть ли у модели действия; есть ли недоверенные источники в контексте.

### 2.9 База калибровки смещена

Два ДА из трёх это агентные харнессы, чей продукт и есть агент; обе калибровки пометили «сильный Н17 отчасти следствие предмета». Единственный обычный продукт с функцией на LLM лёг на Н17 плохо. Критерий откалиброван на том, для чего написан, и не откалиброван на том, где будет применяться чаще.

### 2.10 Чего нет

- Вывод модели как источник для запросов и команд: это Н26, ссылки нет.
- Постоянная память агента, которую инъекция отравляет на будущие сессии: не названа ни в Н17, ни в С; у flutter_agent_harness каталог памяти идёт в системный промпт.
- Оценочные наборы для собственных промптов исключены как требующие истории; это надо записать в §10 явно.

## 3) Кандидаты в правки

Растворить Н17 по образцу типа «хранит данные», оставив ему один собственный эффект.

| Куда | Что добавить с условием «компонент с LLM» |
|---|---|
| Н3, Я3 | модель это внешний источник: схема ответа проверяется; двойник модели в обвязке возвращает враждебный и повреждённый вывод, негативные тесты именованы |
| Я6 | действия модели проходят ярусы инструментов и перехватчик разрушительных команд; аварийный выключатель; правка автомата не уничтожает работу человека |
| Н4 | потребление ограничено бюджетом с тестом превышения: токены, вызовы, глубина цикла; модель как зависимость, которая может отказать и зависнуть |
| Я15 | версия модели в конфигурации как зависимость; смена модели это изменение с прогоном, не тихое обновление |
| Н23, Н26, Я21 | ссылки: секреты не в транскрипте; вывод модели недоверенный ввод для запросов и команд; извлечённые документы это путь к данным |
| Н27 | инъекция в промпт как названная угроза с контрмерой и проверкой |
| Н17, новый эффект | «Действие, вызванное недоверенным контентом в контексте модели, не превышает яруса, доступного пользователю». Условие: модель имеет действия и читает недоверенные источники. Артефакт: корпус инъекций в обвязке с утверждением «привилегированное действие не произошло»; карантин и типизация недоверенного текста как механизмы, засчитываемые по тесту |
| §10 | пиннинг модели не наблюдён ни на одной калибровке; постоянная память агента не названа; оценочные наборы вне объёма |

Коды сохраняются: Н17 остаётся, его объём сужается. Вердикты калибровок пересчитываются по подпунктам при следующем прогоне; ожидаемо Documenso получит Н17 Н/П по новому условию (модель без действий) и отдельные вердикты по Н3, Н4, Я15.

Что проверить до правки: есть ли у Gnomish Factory и flutter_agent_harness двойник модели с враждебным выводом в обвязке; читает ли что-нибудь версию модели из конфигурации; идёт ли память flutter_agent_harness в контекст без карантина.
