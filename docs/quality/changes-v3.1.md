# Карта v3.0 → v3.1: замены из трёх проб

**Дата:** 2026-10-20. **Что сделано:** в `definition.md` внесены шесть правок по итогам проб версии 3.0 на Pydantic (`calibration-pydantic.md`), LiteLLM (`calibration-litellm-external.md`, без чтения дерева) и OpenHands (`calibration-openhands.md`). Состав критериев, их коды, утверждения и условия включения не менялись; добавлены замены и одно правило применения. v3.0 сохранена в `definition-v3.0.md`.

Отбор правок делал сопровождающий 2026-10-20 из двенадцати кандидатов черновика; критерий отбора: правка меняет то, что делает команда, пишущая ПО с агентами, а не только то, как оценивают чужой репозиторий.

## 3) Состояние проверки на практике после трёх проб

- Подтверждены артефактами в обвязке живых проектов: Я10 с исполнением примеров документации и докстрингов (Pydantic); Н8 для библиотеки с детерминированной метрикой (Pydantic); К7 «минимальный возраст публикации» (Pydantic, OpenHands) и «проверка разницы lockfile» (OpenHands, на релизе); Н16 с полом совместимости, проверкой разрыва REST API и совместимости сохранённых настроек (OpenHands); механизмы абзаца «вызывает LLM»: ярусы, подтверждение, аварийный выключатель, бюджеты, повреждённый ответ модели, редактирование секретов в телеметрии (OpenHands).

- Не сдвинуто: пороги §10 (К5, Н1, Н10, Н11, Н8) не измерены, прогоны не запускались; заказной профиль не проверен; Н19 без корпуса инъекций ни у кого.
