# Прогон v1.3 по девяти калибровкам: что изменилось в вердиктах

**Статус:** записано 2026-10-19. Каждая калибровка делалась по той версии определения, что была на момент пробы: curl, SQLite и отрицательный контроль по v0; Clear Progress, Gnomish Factory, herdr и flutter_agent_harness по v1; Documenso по v1.1; GitLab.com по v1.2. Здесь к фактам каждой калибровки применены правила более поздних версий, вплоть до v1.3. Факты не пересобирались, кроме четырёх проверок по сохранённым клонам, которых старые калибровки не содержали: повторы тестов в CI (Я5 v1.2), разрешение ссылок в инструкциях агенту (К5 v1.2), политика установочных скриптов (Я15 v1.2), отказ от значений примера конфигурации при старте (Я17 v1.2).

Обозначения: «→» смена вердикта; в скобках версия правила, которое её вызвало. Строки без изменений не перечислены. «не перепроверено» значит, что новое правило требует факта, которого в калибровке нет и который по клону не восстановить.

## 10) Сводка

Смены вердикта по правилам v1.2 и v1.3, без учёта v1 и v1.1:

| Правило | Кого задело | Направление |
|---|---|---|
| Я7 v1.2: хуки не засчитываются, обвязка не подчинена автору | SQLite, Documenso | вниз |
| Я5 v1.2: отказ в заглушку, повторы | Documenso вниз; А2 отрицательного контроля в ЛОВИТ | обе |
| Я17 v1.2: отказ от значений примера | Documenso вниз; Clear Progress не перепроверено | вниз |
| К5 v1.2: ссылки разрешаются, один источник | Clear Progress, herdr, Documenso | вниз |
| Н6 v1.2 и v1.3: репетиция, сторож, публичность | Documenso вниз; GitLab Postgres без изменений | вниз |
| К2 и С5 v1.3: локальный хук не защита | herdr | вниз |
| §3 v1.3: чекбокс равен прозе | GitLab Н12 | вниз |
| Я10 v1.3, Я12 v1.3, К7 v1.3, Н13 v1.3, Н15 v1.3 | никого | без смен |

Три наблюдения.

1. **Новые правила только ужесточают.** Из девяти смен по v1.2 и v1.3 восемь вниз. Единственный подъём это отрицательный контроль. Правила v1 и v1.1, напротив, подняли curl с 9 до 16 ДА: там исправлялась формулировка, здесь закрываются обходы.
2. **К5 с проверкой ссылок проваливают четыре проекта из пяти проверенных.** Битые пути в инструкциях агенту: Clear Progress 3 из 12, herdr 5 из 13, Documenso 2 из 2, fah 40 из 173; чист только Gnomish Factory. Это самое дешёвое из правил v1.2 и самое частое нарушение.
3. **Правило v1.3 о чекбоксах ударило по своему источнику.** GitLab Н12 для инфраструктуры снизился до ЧАСТИЧНО. Это ожидаемо: калибровка записала ДА до того, как правило было сформулировано, и факт 7 из 20 был в той же таблице.

Что требует новых фактов, а не перечитывания: Я17 у Clear Progress (запуск с примером конфигурации), Я5 по повторам у GitLab (CI приложения не смотрели), Н12 v1.3 «триггер отката» у всех, кроме GitLab (поле в шаблонах PR никто не проверял).
