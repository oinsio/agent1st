- нагрузка от собственных автоматов (Н5, бывш. Н4) ни на одной пробе не встречалась;
- условие Н8 (бывш. Н20) «работа множится на кардинальность» проверено на одном проекте, Gnomish Factory; второй проект покажет, не делает ли оно критерий применимым ко всем;
- Н4 (бывш. Н21) не откалиброван: у всех проб с интерфейсом один вердикт по одной причине, нужен проект со сквозными сценариями по пользовательской документации в обвязке;

- заказной профиль §8 не проверен ни одной пробой;
- артефакты, записанные по инцидентам и практике индустрии и не наблюдённые ни на одной пробе: тест на отсутствие персональных данных в логах (Н22, бывш. Н23); двойник модели с враждебным выводом и версия модели в конфигурации (абзац «вызывает LLM» §6); каталог идентичностей агента и перегенерация прав из активности (С4); файл владельцев кода для защищённых путей (С5); негативный тест удаления копии из-под идентичности агента (С3);
- гипотезы о поведении моделей (К4–К6, бывш. К3–К5) подтверждены наблюдениями на проектах проб, но не исследованиями на агентах;
- шкала §3 с версии 2.3 даёт неподключённому артефакту НЕТ вместо ЧАСТИЧНО; прогон 2.3 должен был показать, не теряет ли оценка различение «ничего нет» и «есть, но не подключено», и не выполнен.
