# Карта доказательств к определению v2.0

**Статус:** записано 2026-10-19 вместе с v2.0. `definition.md` с версии 2.0 не содержит отсылок к проектам; здесь для каждого правила указано, где оно родилось и на чём проверено. Источники: `calibration-curl.md`, `calibration-sqlite.md`, `negative-control-incidents.md`, `calibration-clear-progress.md`, `calibration-gnomish-factory.md`, `calibration-herdr.md`, `calibration-flutter-agent-harness.md`, `calibration-documenso.md`, `calibration-gitlab-com.md`; фильтры `documenso-generalization.md`, `gitlab-com-generalization.md`, `generalization-v1-v1.1.md`; прогон `rerun-v1.3.md`.

Сокращения: curl, SQLite, НК (отрицательный контроль), CP (Clear Progress), GF (Gnomish Factory), herdr, fah (flutter_agent_harness), Doc (Documenso), GL (GitLab.com).

## Следствия и правила зачёта (§1, §3)

| Правило | Родилось | Подтверждено | Версия |
|---|---|---|---|
| Объект поставка, не код; автора завтра нет | curl, SQLite | все | v1 |
| Артефакт только по эффекту; шаблон и проза не засчитываются | fah (шаблон `SECURITY.md`), herdr (правило без lint) | CP, Doc (`.catch(() => null)` при правиле «handle errors»), Doc (Dependabot с нулевым лимитом) | v1.1 |
| Чекбокс шаблона равен прозе | GL (dry-run отмечен в 7 из 20 при статусе «complete») | GL Н12 снижен при прогоне | v1.3 |
| Инструкция оператору только отрепетированная | Doc (бэкап, откат, диагностика без прогона) | GL (репетиции с измерениями) | v1.2 |
| Проверка, которую можно пропустить одной переменной, не проверка | Doc (`HUSKY=0` в CI) | SQLite при прогоне v1.3 (прогон у авторов) | v1.2 |
| Артефакт вне репозитория по публичной ссылке | curl (OSS-Fuzz, secret scanning) | SQLite, GL | v1 |
| Приватное только для «доказано себе» | SQLite (TH3, dbsqlfuzz) | Doc Cloud | v1 |

| Цена проверки видна | GF (1 ч 24 мин на прогон), fah (бюджеты храповиком) | | v1.1 |
