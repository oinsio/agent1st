# Изменения версии 2.3 относительно 2.2 и их происхождение

**Назначение:** карта правок версии 2.3 `definition.md`. Это выпуск непротиворечивости: источник каждой правки `consistency-v2.2.md`, номера его пунктов указаны в колонке «Источник». Планка не менялась: ни один критерий не добавлен и не удалён, ни одно требование не ослаблено; менялись место записи, формулировки вердиктов и перекрёстные ссылки. Продолжает `changes-v2.2.md`. Прогон версии 2.3 по калибровкам не выполнен; ожидаемые смены вердиктов в §5.

Два решения сопровождающего, из которых выведено остальное (2026-10-19): вердикт ставится по эффекту, видимому принимающему, и потому неподключённый артефакт даёт НЕТ, а приватный градуируется по публичным следам; защищённый путь меняется только отдельным изменением через владельца пути, агент автор, но не одобряющий и не применяющий.

Обозначения калибровок: curl, SQLite, Инц, CP (Clear Progress), GF (Gnomish Factory), herdr, fah (flutter_agent_harness), Doc (Documenso), GL (GitLab.com).

## 5) Что не тронуто и почему

- **Текст определения в §1** не изменён, включая «собраны до того, как изменение достигнет пользователя» (п. 22 разбора). Напряжение с периодическими проверками Я14, Н6, Я19 записано, но правка определения выходит за выпуск непротиворечивости.
- **Замены по истории эксплуатации** (Я13, Н21) не удалены, а помечены; удаление это решение о планке, оно в §10.
- **Н20 для типа «под нагрузкой»** по-прежнему берёт нагрузочный прогон как артефакт по умолчанию при предпочтении детерминированной метрики (п. 24): осознанный выбор типа, текст не менялся.
- **Колонка «Замены» у Я17** по-прежнему содержит правила зачёта, а не замены: стиль, не противоречие.
- **Пороги, частоты и прочее из §10** не трогались.
